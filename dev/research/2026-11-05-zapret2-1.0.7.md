## Relevant changes

- Windows adds optional `--wf-priority` (-30000..30000, default0); upstream blockcheck selects2000. Our ordinary command keeps its existing default.
- Hostlists support local negative entries with `!`. Repeated same-type references to the same list within one profile now fail registration. Compatibility therefore needs native configuration validation.
- Windows raw filter storage is limited to16KiB; the native compiler/token limit still matters.
- CGNAT support in the optional UDP-to-ICMP obfuscator requires that separate client/server setup; this package does not load zapret-obfs.lua. Linux hardware-offload changes are outside the Windows package.

Among this package's eight official files only winws2.exe changes: new SHA256 `9f25492575ff7c3f9e0d6211daac85704c309a0ca695423f0276d9ebde3156aa`. WinDivert.dll, WinDivert64.sys, cygwin1.dll, the three official Lua scripts and the QUIC filter fragment match their existing bytes.
