## Что ещё не считается стабильной приёмкой

- Реальный длительный A/B с1.9, сон/пробуждение, смена Wi-Fi и включение/выключение TUN на пользовательской установке. Живую сеть, адаптеры, маршруты и действующую службу этим ходом не меняли.
- Native store timer/file I/O, фактическое истечение timer и отдельный native Lua-run требуют administrator token и условно пропущены в данном общем прогоне; developer Lua fixtures исполнены. Не обходить UAC через SYSTEM-задачи.
- Онлайн GitHub CI/upload этим ходом не выполнялись; архив не публиковался. Перед стабильным выпуском проверить workflow и digest загруженного актива.
- Материализованный снимок теперь реализован для явных тестов стратегий. Общий canonical recipe для всех способов запуска и автоматический возврат последней рабочей конфигурации движка остаются отдельными этапами roadmap; текущие fingerprints, финальный replay и файловый rollback не выдаются за эти механизмы.
- Нет доказанного уменьшения игрового RTT. Сужение перехвата, ограничение памяти и показатели HTTPS/кадров не заменяют измерение задержки игрового транспорта.
