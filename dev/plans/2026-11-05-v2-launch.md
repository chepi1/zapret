## Design

One owned launch recipe contains a frozen settings copy, the exact Windows command line, original native executable/bin paths, static-input digest and a configuration digest. Hold read/no-delete leases on original static files and their package directories across composition, native preflight and startup. Do not execute native binaries from TEMP. Auto-learning files and ring state stay writable and are explicitly outside the static digest. Detect input catalog/code drift before destructive actions; reject unknown or closed handles. Existing Get-BypassCmdLine remains a compatibility composer.

Use the same recipe in normal startup, service installation, the service-failure probe, visible diagnostics and strategy-test startup (including the lifetime guard in the recipe). Release leases in finally. Experimental recipes cannot be recorded as working configurations.

Store only validated engine settings and digests, never executable command text, in an ACL-protected local runtime/launch-state record. Flush and atomically replace it only after a stable process check. On a failed replacement with no surviving process, try the previous confirmed configuration once; rebuild with current trusted code and require an exact digest match before stopping/launching. Preserve Telegram/notification settings. Do not recover after a preflight refusal, a failed stop, game detection or changed files. Report restoration separately from applying the requested settings.
