# V2: наблюдатель подтверждает только загруженный код

> Выполнить inline через superpowers:executing-plans: RED → GREEN → целевые проверки → одно независимое read-only ревью → локальный коммит.

**Goal:** старый PowerShell-наблюдатель после обновления файлов не публикует heartbeat с составом новой сборки, продолжая использовать прежнюю реализацию.

**Причина:** netwatch загружает lib/netstate/linkguard один раз, а Get-RingCompositionKey каждый цикл хеширует текущие файлы. Новые network-v4/другие изменения не действуют в уже работающем процессе; одновременно новый экземпляр может выйти из-за занятого lease.

**Решение:** tools/watchcode.ps1 снимает SHA256 UTF-8 BOM исходников из корневых AST реально загруженных функций tools и собственного entry AST. На настоящем PS5 подтверждено совпадение AST+UTF8 BOM с raw SHA256 всех8 существующих модулей. Снимок небольшой, без хранения AST/исходных текстов в состоянии цикла. Get-ScoreInputsHash/Get-RingCompositionKey получают необязательный ExpectedCode и сверяют уже читаемые SHA256 с этим снимком; каждое ожидаемое имя должно входить в manifest. Сверка не добавляет второго прохода по source в обычном цикле и не добавляет CIM-запросов. Все штатные вызовы без ExpectedCode сохраняют контракт.

При отказе композиции дополнительная проверка различает Changed и Unknown. Changed снимает оба маркера под lease, освобождает lease и через2с один раз запускает новый наблюдатель. Перезапуск разрешён лишь после подтверждённого совпадения загруженного кода: неполный/невалидный пакет при старте не образует цикл самоперезапусков. Unknown (в том числе временная блокировка файла) снимает маркеры и повторяет наблюдение через5с. Свежие link/network записи публикуются только после проверки кода. Изменения настроек/списков не требуют перезапуска наблюдателя.

**Границы:** PS5.1, UTF8 BOM; без новых зависимостей. Живые процессы/службы/адаптеры не менять во время разработки; тесты на TEMP с имитацией handoff. Без bump1.9, публикации и обещаний снижения RTT. Четыре личные untracked заметки не трогать. Это проверка совместимости собственного кода, не механизм аутентификации/защиты от злонамеренной подмены.
