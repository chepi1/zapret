# V2: компактный фильтр одиночных IPv4 исключений

Полный offline-прогон выявил существующий отказ capturetest: с текущей основной «ALT11 белый 6» и 32 одиночными IPv4 /32 команда после компактизации занимает 33742 символа, до изменений кэша (HEAD07782b8) — 33655. Отдельная TEMP-проверка с обычными настройками проходит; воспроизведение требует этой основной стратегии. Предел приложения32000, Windows32767. Текущие четыре игровые подсети не затронуты.

Для /32 обе границы совпадают: выражение «адрес меньше X или больше X» заменить эквивалентным «адрес не равен X». Сохранить порядок, дедупликацию, общий launch snapshot и полные CIDR-списки профилей; для подсетей оставить существующие диапазоны. Это сокращение представления того же фильтра, без изменений живого обхода.

Проверки: граничный capturetest фиксирует основную60 явно; настоящий WinDivertHelperEvalFilter проверяет каждый адрес32-host снимка и соседей для исходящих TCP/UDP и входящих управляющих TCP. Никакого открытия сетевого драйвера этими helper-проверками. После фикса — capturetest, check/lintstrat/drystrat, полный offline-прогон и read-only ревью.

Результат: capturetest exit0; длина31749 в отдельной TEMP-копии,31758 в полном прогоне.502 native packet cases и3 полных фильтра прошли реальный helper compiler/evaluator. Финальный run-all -Offline:46 групп, exit0. Независимое ревью дополнительно проверило55 случаев эквивалентности, включая крайние IPv4, IPv6 и входящий UDP; замечаний нет. git diff --check чистый.

Сокращение относится к одиночным /32; существующий контроль длины команды остаётся необходимым для произвольных пользовательских конфигураций. Сохранение локальное, без публикации и изменения живого обхода.
