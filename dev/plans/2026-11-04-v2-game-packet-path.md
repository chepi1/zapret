# V2: убрать лишний перехват игрового TCP

**Задача:** пользователь уточнил, что хочет уменьшить задержку самой игры, без конкретного сбоя. Работа касается пути пакетов во время игры, не скорости автоподбора.

**Основание:** в сохранённом журнале NBA есть TCP-соединения к Take-Two. Четыре сети Take-Two уже исключены из всех native-профилей одним неизменяемым снимком. Предыдущая оптимизация пропускает исходящий IPv4 UDP к ним мимо WinDivert, но TCP всё ещё проходит через userspace без обработки стратегиями. WinDivert рекомендует сокращать перехват ненужного трафика: https://github.com/basil00/WinDivert/blob/master/doc/windivert.html .

**Решение:** распространить существующий ограниченный kernel-фильтр на исходящий IPv4 TCP к тем же сетям. Снимок native-профилей, валидация списка и fallback остаются общими. Входящие пакеты, IPv6, соседи CIDR, Valve/Steam relay и прочие назначения сохраняют прежний путь. Повторы фейков и диапазоны игровых портов не менять. Вызовы драйвера для фактического перехвата, настройки пользователя и работающий обход не трогать.

**Проверка:** сначала RED на реальном WinDivertHelperEvalFilter для TCP к Take-Two; затем минимальное изменение компилятора. Матрица охватывает границы каждой сети, TCP SYN/ACK/data/FIN/RST, игровые/веб-порты, входящие, IPv6 и соседние адреса. Выполнить capturetest, astlint, check, lintstrat, drystrat на TEMP-копии под PS5.1. Независимое read-only ревью по requesting-code-review. Измеренное снижение RTT или задержки матча не утверждать: тесты подтверждают сокращение перехвата, не миллисекунды.

## Продолжение: входящие TCP control packets

Base54994e5. После продолжения пользователем проверяем оставшуюся лишнюю обработку входящих SYN+ACK/FIN/RST от тех же четырёх сетей. Предыдущее ревью подтвердило, что они завершаются VERDICT_PASS без Lua/desync: ни один профиль не обрабатывает это соединение. Можно убрать и этот перехват, не оставляя осиротевшие записи conntrack.

Вторая AND-оговорка kernel filter проверяет IPv4 SrcAddr только у входящего TCP. Для исходящего трафика по-прежнему проверяется DstAddr; адрес локальной стороны не должен ошибочно исключать другое соединение. Входящий UDP не менять. Общий неизменяемый снимок, все fallback, IPv6, соседи CIDR и остальные назначения сохраняются. Настройки/движок/службы не перезапускать. Эта часть сокращает обработку установки/закрытия TCP, но не обещает меньший постоянный игровой RTT.

- [x] RED: старый фильтр всё ещё перехватывает TCP control packets с удалённым Take-Two SrcAddr.
- [x] GREEN: реальные экспортированные фильтры используют правильный адрес для каждого направления.
- [x] Проверки композиции, read-only ревью и локальное сохранение.
