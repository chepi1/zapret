# Zapret v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** повысить устойчивость обхода и уменьшить измеренную стоимость обработки, обеспечив проверяемый выбор стратегии и восстановление после сбоев.

**Architecture:** оставить официальный winws2/Lua и совместимое PowerShell-управление. Выделять из lib.ps1 небольшие компоненты с явными контрактами: снимок окружения, описание итоговой конфигурации, измерение/выбор, управление/восстановление. Сохранять существующие функции как совместимые оболочки до миграции вызывающего кода.

**Tech Stack:** Windows PowerShell 5.1, .NET Framework, официальный zapret2 v1.0.6 как стабильная база, Lua; существующие PowerShell/Python-тесты. Новые бинарные зависимости требуют отдельного обоснования.

**Spec:** `dev/research/2026-11-03-v2-review.md` — исследование, подтверждённые пробелы, требования и границы.

## Global Constraints

- База для сравнения — v1.9 / `23c14e6ae6f9c2fa5a776d37a98bdc09c5c80452`.
- PS5.1, BOM для PowerShell, сохранение принятой кодировки/окончаний строк; dev-файлы исключаются из пользовательского ZIP.
- Пользователь использует Wi-Fi. Кабель и изменение роутера/NIC не являются условием улучшения.
- Открытая игра запрещает фоновые перезапуски. Исследовательские тесты по умолчанию выполняются на временных копиях, без живого WinDivert-перехвата.
- Не менять стабильную версию/бинарники и не публиковать v2 до завершения этапов приёмки. Живые A/B-сеансы выполняются отдельным явно обозначенным этапом.
- Никаких обещаний уменьшения игрового пинга по результатам HTTPS-тестов; численные цели задаются после baseline.
- Не публиковать runtime, SSID, внешние IP, PAC-URL и секреты. Локальный сетевой ключ не требует внешнего geo-IP запроса.
- Сохранять настройки, пользовательские списки и происхождение заимствованного кода. Не объединять несовместимые условия участников circular.

## Review Focus

- Сеть/списки меняются во время измерения: результаты не применяются к новому состоянию (задача 1).
- Наблюдение невозможно из-за прав/тайм-аута: сохраняется Unknown, а не ложный Closed/Offline (задача 2).
- Две стратегии имеют одинаковое имя, но разные условия/байты: не разделяют один fingerprint и неподходящий круг (задача 3).
- Поздняя стратегия выигрывает только из-за временного улучшения Wi-Fi: контроль дрейфа выявляет недостоверное сравнение (задача 4).
- Позднее внедрение нового формата не должно потерять старые пользовательские данные: сначала shadow-режим и точная резервная копия (задачи 1–4).
