**zapret 2.0 — большое обновление**

Сборка для YouTube и Discord на Windows на основе zapret2 от bol-van и стратегий Flowseal. Теперь со встроенным официальным TG WS Proxy для Telegram.

Что нового:
- Telegram: WebSocket и резервные CF/H2-пути, управление через **7 → 8**.
- Проверка параметров до перезапуска и восстановление подтверждённой конфигурации при неудачной замене.
- Более строгий автоподбор и учёт Wi-Fi, Happ, прокси и TUN.
- Обновления с сохранением личных данных и восстановлением после прерывания.
- Светло-розовое и сиреневое меню, понятные статусы и отдельные уведомления.

**Скачать:** https://github.com/chepi1/zapret/releases/latest
**Инструкция:** https://github.com/chepi1/zapret

Распакуйте архив → `zapret.bat` → **5** проверка → **1** запуск → **3** автоподбор. Обновиться можно через **Настройки → 9**.

Работа зависит от провайдера; уменьшение игрового пинга не обещается.
