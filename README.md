# zapret

Обход DPI для **NBA 2K27**, **Discord** и **YouTube** на Windows. Основа — [zapret2](https://github.com/bol-van/zapret2) (winws2) от bol-van и стратегии [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube), переписанные на zapret2.

*DPI bypass for NBA 2K27, Discord and YouTube on Windows, built on bol-van's zapret2 with Flowseal's strategies. The interface is in Russian. English: [README.en.md](README.en.md).*

[![tests](https://github.com/chepi1/zapret/actions/workflows/tests.yml/badge.svg)](https://github.com/chepi1/zapret/actions/workflows/tests.yml)

Это не VPN и не прокси. Трафик идёт напрямую с вашего IP через вашего провайдера: обход только подмешивает несколько фейковых пакетов в начало соединений. Поэтому пинг в игре такой же, как без обхода.

## Зачем

Многие российские провайдеры замораживают соединения к зарубежным хостингам — AWS, Cloudflare, Hetzner — после первых 16–20 КБ. На таких хостингах работают игровые серверы NBA 2K и Easy Anti-Cheat. Игра пускает в Город, но выкидывает из матча. Discord и YouTube заблокированы отдельно.

Сборка закрывает всё это одним обходом, Flowseal не нужен.

## Возможности

- **27 стратегий**:
  - все 22 стратегии Flowseal 1.10.4;
  - 3 стратегии из документации bol-van;
  - 2 «мягких» варианта ALT11 и ALT12, которые не ломают сайты на Akamai.
- **Автоподбор**:
  - без обхода и с каждой стратегией проверяет заморозку 16–20 КБ на 36 хостингах (набор [dpi-checkers](https://github.com/hyperion-cs/dpi-checkers), тот же, что у Flowseal);
  - проверяет Discord, YouTube, SoundCloud, серверы 2K и EAC;
  - проверяет **вред**: не перестали ли открываться или замедлиться обычные незаблокированные сайты и Steam;
  - сбойные адреса перепроверяет второй попыткой;
  - бывает быстрый (~4 мин) и полный (~8 мин).
- **Автосмена стратегии для каждого сервера** (`circular` из zapret2). Если сервер 3 раза подряд не ответил, он переходит на следующую стратегию, остальные соединения не трогаются. У сайтов, YouTube, Discord и игры свой круг стратегий, по результатам автоподбора на вашем провайдере.
- **Серверы 2K (Take-Two) не обрабатываются никогда**: иначе Easy Anti-Cheat выдаёт ошибку `fee12ea9`.
- **Серверы Valve (Steam, Dota 2, CS2) тоже не обрабатываются**: часть ретрансляторов Доты стоит у хостингов из списков Flowseal, и фейки ломали поиск и вход в матч. Адреса берутся из официального конфига Steam и обновляются вместе со списками.
- **Автосписок сайтов** (`--hostlist-auto`): сайт вне списков, который 3 раза подряд не открылся, дальше идёт через обход сам.
- **Трекер** показывает, где сервер матча, какой до него пинг и куда ходят игра или Discord. **Сканер** находит адреса игры, которые обход не покрывает.
- **Проверка обходов одним пунктом** — и в конце список того, что исправить:
  - подключение: VPN, прокси, игровые ускорители вроде ExitLag, другой обход, программы, которые конфликтуют с WinDivert (Killer, Check Point, SmartByte, AdGuard), служба Base Filtering Engine, папка в OneDrive;
  - IPv6: при сломанном IPv6 Steam ждёт по 20 секунд, есть настройка «предпочитать IPv4»;
  - записи hosts Flowseal: ставятся только те, что реально помогают;
  - автосписок: адреса, попавшие туда по ошибке, убираются.
- **Автонастройка по расписанию**: раз в неделю, когда ПК простаивает, полный автоподбор; раз в месяц свежие списки Flowseal; уведомление о новых версиях zapret, zapret2 и Flowseal.
- **Проверка провайдера** (Инструменты → 3): что режет любой провайдер и какая стратегия там лучшая — отчётом в один файл, его удобно переслать.

## Быстрый старт

1. Скачайте архив из [Releases](../../releases) и распакуйте в простой путь без русских букв и пробелов, например `C:\zapret`.
2. Добавьте папку в исключения антивируса. `WinDivert64.sys` — драйвер перехвата пакетов, антивирусы часто ругаются на него ложно.
3. Полностью выйдите из VPN, прокси-клиентов (Happ, v2rayN…) и игровых ускорителей (ExitLag…): в трее «Выход», а не «Отключить».
4. Запустите `zapret.bat`, он попросит права администратора. Затем по очереди:
   - **5** — проверка обходов: российский IP, без VPN и ускорителей, IPv6, hosts;
   - **1** — запуск обхода; если работает Flowseal, меню предложит его остановить;
   - **3** — автоподбор: покажет, что режет ваш провайдер, и выберет стратегию.
5. Когда всё работает:
   - **Настройки → 6** — служба, обход будет стартовать вместе с Windows;
   - по желанию **Настройки → 7** — автонастройка по расписанию.

Обход работает в фоне без окна. Работает он или нет и с какой стратегией, видно в верхней строке меню.

### Проверить свой провайдер

Распакуйте папку, выйдите из VPN и прокси, запустите `zapret.bat` и выберите **7 → 3**. За ~10 минут проверка определит, что режет провайдер и какая стратегия у вас лучшая, и положит на рабочий стол файл `zapret-proverka-<провайдер>-<дата>.txt`. Последняя часть IP в нём скрыта. Обход сам не включается: в конце проверка спросит.

## Стратегии

Каждая стратегия — файл `strategies\altNN.txt` с секциями под все профили: QUIC, голос Discord, discord.media, YouTube, общий список, сети ipset-all, игровой TCP и игровой UDP.

| № | Имя | Устройство |
|---|---|---|
| 10 | ALT10 | только фейки (stun + ClientHello 4pda.to) с устаревшим TCP timestamp, без разрезки |
| 11 | ALT11 | фейки (stun2 + sferum.ru) и разрезка с ложным началом (seqovl 664) |
| 12 | ALT12 | как ALT11, первый фейк stun; основная по умолчанию |
| 13 | ALT13 | фейки (sochi.park + stun2) и подмена имени хоста на mail.ru (hostfakesplit) |
| 31, 32 | ALT11 / ALT12 мягкая | как ALT11/ALT12, но для сайтов без ложного начала: щадят серверы Akamai |
| 21–23 | BV1–BV3 | стратегии из документации zapret2: MD5-опция, сдвиг sequence, обратный порядок частей |
| 1–9 | ALT, ALT2–ALT9 | остальные ALT Flowseal: fakedsplit, syndata, badseq, hostfakesplit и др. |
| 40 | GENERAL | обычный `general.bat` Flowseal: разрезка с ложным началом без фейков |
| 41 | EXP | экспериментальная Flowseal: фейк sferum и разрезка с ложным началом из stun2 |
| 42–44 | SIMPLE FAKE, ALT, ALT2 | только фейки, без разрезки |
| 45–48 | FAKE TLS AUTO, ALT, ALT2, ALT3 | стандартный фейк с SNI google, badseq или timestamp и разные разрезки |

Какая стратегия лучшая, зависит от провайдера. В наших проверках у трёх провайдеров лучшими оказались три разные стратегии: ALT10, ALT и ALT13. Поэтому и нужен автоподбор.

Чего нет в zapret2 и потому не перенесено: `altorder=1` (ALT3, ALT13), фильтр «только IPv4» у ALT5, неизвестный UDP в голосе Discord у EXP.

## Частые проблемы

**Discord не запускается или висит на загрузке.** **Инструменты → 9** очистит его кэш, как у Flowseal: вход и настройки останутся. Если Discord запускали при включённом прокси, а потом прокси выключили, его надо перезапустить — проверка обходов (пункт **5**) это заметит.

**Telegram тормозит, не грузятся фото и видео.** **Инструменты → 8**: tg-ws-proxy от Flowseal. Сборка скачает его с GitHub Flowseal, сверит контрольную сумму, запустит от вашего имени и откроет Telegram с вопросом о прокси — ответьте «Подключиться».

**Discord работает, а голос нет.** Обычно мешает программа, которая сама перехватывает трафик:
- игровой ускоритель (ExitLag и т. п.);
- прокси-клиент в режиме системного прокси: через него идёт TCP, а голос (UDP) — напрямую, мимо прокси.

Закройте их полностью и перезапустите Discord (трей → Quit Discord). Если не помогло — **Инструменты → 1 → 2** (трекер, Discord): посидите минуту в голосовом канале, трекер покажет, отвечает ли голосовой сервер.

**Easy Anti-Cheat: «unable to authenticate» (fee12ea9).** Выключите автосмену (**Настройки → 2**) и проверьте, что в `lists\ipset-user.txt` не попали сети Take-Two. Серверы 2K сборка исключает сама.

**Dota 2: не нажимается «Играть», не пускает в матч.** Начиная с zapret 1.2 серверы Valve обход не трогает. Если не помогло, проверьте, не идёт ли Steam через прокси-клиент (Happ и т. п.): в режиме системного прокси Steam подключается к своим серверам через него, и сервер Steam рвёт подключение. Выйдите из прокси полностью и перезапустите Steam.

**Другая игра с обходом работает хуже, чем без него** (не находит матч, вылетает, ругается античит). Её серверы, скорее всего, стоят у хостингов из списков Flowseal. Запустите игру и трекер (**Инструменты → 1**, имя процесса игры), поиграйте пару минут, затем **Инструменты → 6** — сборка предложит исключить эти сети из обхода.

**Steam долго качает, сайты долго открываются.** Пункт **5**: у некоторых провайдеров часть сетей IPv6 не отвечает, а Windows пробует IPv6 первым. Проверка предложит «предпочитать IPv4».

**Перестал подключаться Telegram (часто после ExitLag или VPN).** Пункт **5**. Пока трафик шёл через ускоритель, соединения рвались, и в автосписок попадали адреса серверов Telegram, после чего обход ломал его запасной канал. Начиная с zapret 1.0 такие адреса убираются сами при каждом запуске обхода, а проверка показывает их, если они появились снова.

**В Городе пусто или выкидывает из матча.** Пока игра в онлайне, запустите **Инструменты → 2** (сканер): он покажет адреса, которые обход не трогает. Для проверки можно временно поставить IPSet any (**Настройки → 4**).

**Обход или автозапуск не запускается.** Меню само покажет причину: что ответила Windows и что написал winws2. Если сбоит только служба автозапуска, обход запустится без неё. Причина попадает и в отчёт (**Инструменты → 4**). **Инструменты → 5** (диагностика) запустит winws2 в окне. Частые причины:
- антивирус удалил или блокирует `WinDivert64.sys` или `winws2.exe`;
- «Целостность памяти» (Безопасность Windows → Безопасность устройства → Изоляция ядра) не пускает драйвер WinDivert;
- запущен другой обход;
- в пути к папке русские буквы.

Не помогло — напишите мне (см. «Связь») и приложите отчёт: **Инструменты → 4**.

## Как это устроено

- Профили повторяют `general (ALT*).bat` Flowseal с Game Filter «TCP и UDP» (порты 1024–65535) и IPSet «loaded».
- Параметры передаются winws2 в командной строке: в Windows-сборке zapret2 файл `@config` не читается. Общий список стратегий описан один раз шаблоном zapret2, чтобы уложиться в предел Windows 32767 символов.
- Из UDP 443 в драйвер попадают только пакеты QUIC Initial, а не весь поток видео.
- Фейки портятся устаревшим TCP timestamp. Если сервер timestamps не поддерживает, фейк портится иначе (`lua\fooling.lua`: MD5-опция и сдвиг sequence), а не уходит целым.
- Перед каждым запуском параметры проверяются `winws2 --dry-run`.
- Рейтинг стратегий по последнему автоподбору хранится в `runtime\test-rank.txt`. В круг автосмены попадают стратегии, которые дают не меньше 60% прироста лучшей, но не больше пяти.

## Обновление и удаление

О новой версии zapret меню сообщает само, строкой в шапке, а **Настройки → 9** ставит её: скачивает архив релиза, сверяет его SHA-256 с GitHub и раскладывает поверх папки. Настройки, рейтинг, ваши списки `*-user.txt` и списки Flowseal остаются. Вручную — архив из [Releases](../../releases).

Перед тем как заменить или удалить папку:

1. **Настройки → 6** (если ставили службу), **Настройки → 7** (если включали автонастройку) и **Настройки → 10** (если включали уведомления).
2. Пункт **2**: он останавливает обход и выгружает драйвер WinDivert. Без этого Windows не даст удалить `bin\WinDivert64.sys`.
3. Закройте меню и удаляйте или заменяйте папку. Чтобы сохранить настройки и рейтинг, перенесите `runtime\` в новую папку.

До zapret 1.0 сборка называлась NBA2K27-zapret2 (версии 2.0–3.3) и запускалась файлом `NBA2K27.bat`. Если у вас стояла она, при первом запуске `zapret.bat` служба автозапуска и автонастройка сами перенесутся под новые имена.

Что сборка меняет в Windows и как это вернуть:
- **TCP timestamps** включаются для фейков, так же делает Flowseal. Вернуть: `netsh interface tcp set global timestamps=disabled`.
- **«Предпочитать IPv4»** и **записи hosts** (если включали проверкой обходов): пункт **2** перед удалением предложит вернуть их как было.
- **Права на папки с кодом** (см. «Безопасность»): пункт **2** возвращает обычные, иначе Проводник при удалении спросит права администратора.

## Безопасность и приватность

**Защита от подмены.** Сборка работает с правами администратора, а служба и автонастройка — с правами SYSTEM. Чтобы этим не воспользовалась чужая программа:
- перед каждым запуском файлы zapret2 (`bin\`, библиотеки `lua\`) сверяются с SHA-256 официального релиза. Если файл изменён, обход не запускается;
- при запуске меню папки с кодом (`bin`, `lua`, `tools`, `strategies`, `fake`, `windivert`) и `.bat` закрываются на запись для всех, кроме администраторов и SYSTEM. По умолчанию папка в `C:\` наследует право «Изменение» для всех пользователей, и программа без прав администратора могла бы подменить скрипт. Папки с данными (`lists\`, `runtime\`) остаются как были;
- скачанное из интернета (списки Flowseal, набор хостингов для теста) никогда не запускается как код: это только данные, и битые или подозрительные файлы не ставятся.

**Что уходит в интернет.** Телеметрии нет. Сборка обращается только к этим сервисам, всегда по HTTPS:
- **ipwho.is**, запасной **ipinfo.io** — узнать провайдера и страну. Без этого проверка не поймёт, идёт ли трафик напрямую. Трекер так же узнаёт, где серверы игры;
- **GitHub** — свежие списки Flowseal, номера новых версий и, по вашей команде (Настройки → 9), архив новой версии zapret;
- **api.steampowered.com** — адреса ретрансляторов Valve, которые обход не трогает (вместе со списками);
- **GitHub Flowseal** — tg-ws-proxy, только если вы ставите его (Инструменты → 8);
- **hyperion-cs.github.io** — набор хостингов для теста;
- **проверочные сайты автоподбора** (`tools\targets.txt`): на хостинги уходят 64 КБ случайных байт.

**Что в отчётах.** Отчёт (Инструменты → 4) и проверка провайдера (Инструменты → 3) делаются, чтобы их пересылать, поэтому:
- последняя часть вашего IP и имя пользователя Windows в путях скрыты;
- список сайтов из автосписка, по которому видно, какие сайты вы открывали, добавляется только с вашего согласия;
- подробный лог winws2 добавляется только с вашего согласия.

Все логи лежат только в `runtime\` на вашем ПК, удалить их можно в любой момент.

## Разработка

Всё в `dev\`. Проверки не перехватывают трафик: winws2 запускается только с `--dry-run`, без прав администратора.

- `dev\flowseal2zapret2.py <папка Flowseal> strategies` переводит стратегии Flowseal в формат сборки. С ключом `--check` сверяет перевод ALT10–13 с готовыми файлами.
- `dev\tests\run-all.ps1` запускает все проверки (без сети - `-Offline`; так же их гоняет GitHub при каждом коммите):
  - кодировку и синтаксис скриптов;
  - `--dry-run` всех стратегий и комбинаций настроек;
  - логику автоподбора и рейтинга;
  - списки, hosts, автонастройку и распознавание ускорителей;
  - защиту от подмены и скрытие личных данных в отчётах;
  - пункты меню и отчёт R целиком.
  Тесты работают на копии папки. Копия с папкой `dev\` на запись не закрывается, чтобы её можно было править без прав администратора.
- `dev\build.ps1` собирает архив для релиза: без `dev\`, с пустым `runtime\`.
