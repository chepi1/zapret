# История версий

## zapret 1.6

- **Новые стратегии ALT11 белый 1, 2, 3, 4, 6.** Это ALT11 мягкая, но фейк ClientHello подписан именем сайта из белого списка провайдеров: max.ru, vk.com, gosuslugi.ru, ya.ru, wildberries.ru.
  - На эти сайты ничего не отправляется. Фейк уходит к тому же серверу, что и настоящий запрос, и сервер его отбрасывает. Имя видит только фильтр провайдера и пропускает соединение.
  - Белые списки у узлов провайдеров разные, поэтому вариантов несколько.
  - В двух автоподборах подряд «белый 1» был лучшим: 46,5 и 47 баллов против 45,5 и 46 у ALT11 мягкой, вред 0. Со второй попытки у него открываются единицы адресов, у ALT11 мягкой — до восьми, то есть сайты открываются с первого раза.
  - Проверены и не вошли в сборку: IP-фрагменты (ломали почти всё), фейки с неверной контрольной суммой (не действовали), fakeddisorder и фейки по TTL (ломали сайты на Akamai). Ещё не вошли комбинации «белых» фейков и вариант с ozon.ru: не лучше «белого 1».
- **Новые стратегии проверяет быстрый автоподбор.** Стратегии со строкой `# since:`, которые на этом ПК ещё не проверялись, он берёт сам. Проверенные запоминаются в `runtime\tested-strategies.txt`. Дальше стратегия остаётся в быстром автоподборе, только если попала в круги автосмены.
- **Автоподбор быстрее.**
  - Адреса, заблокированные по IP (их находит прогон без обхода), стратегиями не проверяются: им записывается тот же провал, баллы не меняются.
  - Адрес, который не открылся ни без обхода, ни тремя стратегиями подряд, больше не перепроверяется второй попыткой: она каждой стратегии добавляла секунды ожидания. Первая попытка у него остаётся. Сайты без блокировки (проверка вреда) перепроверяются по-прежнему.
- **Пинг до роутера (Инструменты → 10).** Обход маршрут до серверов не меняет: пинг задают провайдер и расстояние. С ПК можно поправить только участок до роутера, и инструмент теперь его меряет: 15 секунд раз в 50 мс, с всплесками и потерями.
- **Wi-Fi: исправление фоновых поисков сетей (проверка обходов, пункт 5).** Пока у адаптера агрессивность роуминга не минимальная, он время от времени ищет другие сети, и пинг в игре прыгает на 50–300 мс. Проверка предложит поставить минимальную; Wi-Fi при этом переподключится на несколько секунд.
- **Проверка обходов предупреждает о российском корневом сертификате в Windows** (Минцифры, Russian Trusted Root CA). Его просят поставить для госсайтов, а с ним в системе HTTPS можно подменить незаметно. Сама сборка сертификаты не ставит и хранилище сертификатов не трогает.
- **Исправлено: проверка новых версий и обновление списков реже срываются.** GitHub иногда отвечает только через 4–5 секунд, а то и не отвечает вовсе. Теперь каждый запрос ждёт до 10 секунд и при сбое повторяется один раз.

## zapret 1.5

### Новое

- **Пинг до игровых серверов (Инструменты → 10).** Серверы матча NBA 2K27 (Amazon, Франкфурт), запись матча, вход и сервисы 2K, соседние регионы Amazon, Steam, Discord. Меряется лучшее время подключения из четырёх попыток.
- **Проверка обходов (пункт 5) показывает, работают ли сервисы прямо сейчас.** YouTube, видео YouTube, Discord, Steam, GitHub, вход в NBA 2K27 (Epic) и запись матча (Quago) проверяются через обход примерно за секунду, с временем TLS. Если что-то не открывается, проверка подскажет запустить автоподбор.
- **Закрепление серверов игр в hosts.** Во время матча NBA 2K27 отправляет запись поведения игрока на `api.quago.io` (Quago, Amazon).
  - DNS отдаёт этому имени то рабочие адреса, то заблокированные провайдером по IP. Например, 3.216.81.164 через VPN отвечает как api.quago.io, а у провайдера не отвечает вовсе.
  - На заблокированном адресе игра ждёт подключения. Обход блокировку по IP не снимает.
  - Проверка обходов предлагает закрепить в hosts только адреса, у которых TLS проходит с сертификатом этого имени. Они перепроверяются при каждом запуске обхода, потому что адреса Amazon меняются.
- **Трекер сам находит серверы, заблокированные по IP.**
  - У каждого рывка игры (пауза в исходящих пакетах матча от 250 мс) трекер пишет, с какими серверами игра и EAC обменивались пакетами рядом с ним, ждали ли ответа и пытались ли подключиться без ответа.
  - Имена серверов берутся из кэша DNS.
  - Серверы, не принявшие подключение, проверка обходов разберёт. Если часть их адресов работает, она предложит закрепить рабочие; если не работает ни один, честно скажет, что нужен VPN.
- **Автоподбор отличает блокировку по IP.** Адреса, которые не открылись ни без обхода, ни с одной стратегией и к которым не проходит даже подключение, он помечает: «заблокированы по IP — только VPN».
- **Game Filter: вариант «только порты игр»** (Настройки → 3 → 7): TCP 20000–27200, UDP 27000–27200 и 30000–30100.
  - Это порты NBA 2K27 и ретрансляторов Steam и Valve. Торренты, звонки и прочие программы на остальных портах обход больше не пропускает через себя.
  - Для других игр — «все порты» (пункт 8).
- **Настройки → 11: удалить zapret из Windows одним пунктом.** Обход, драйвер WinDivert, служба, задачи планировщика, записи zapret в hosts, права на папки. После этого папку можно просто удалить.
- В шапке видно, сколько работает обход. После обновления через меню показывается, что нового.

### Быстрее

- **Меню открывается вдвое быстрее** (~0,4 с вместо ~0,9 с):
  - проверка новых версий на GitHub идёт в фоне — раньше при медленном GitHub меню ждало до 20 секунд;
  - модуль планировщика задач (~0,4 с) грузится, только когда задача правда есть: это проверяется по реестру;
  - поиск игровых ускорителей — 10 мс вместо 80.
- **Проверка обходов — ~7 секунд вместо ~18.** Пробы IPv6, hosts и сервисов идут одновременно.
- **Обход запускается примерно на 2 секунды быстрее.** Запуск засчитывается, когда winws2 проработал чуть больше секунды, а не через фиксированные 3 секунды. Командная строка собирается один раз.
- **Мост Telegram не висит на заблокированных дата-центрах.** Раньше DC1, DC3 и DC5 каждую минуту отнимали у Telegram по 5–13 секунд ожидания. Теперь после каждого провала подряд мост не трогает такой дата-центр всё дольше: 1, 2, 4, 8, 15 минут.
- **Списки сайтов обновляются раз в неделю:** меню скачивает их в фоне, автонастройка тоже. Если списки старше трёх недель, шапка предупредит.

### Исправлено

- **Круг автосмены сайтов снова собирает автоподбор (откат 1.4).** Стандартный круг пускал ALT11 и ALT12 с разрезкой seqovl, и сайты на Akamai (Bing, Adobe, Sony и др.) висели на установке TLS. У игры круг остаётся стандартным.
- **Поправка к 1.4: статтеры NBA 2K27 тогда исправлены не были.** Игра лагала и на той же конфигурации, что в 1.1. Главная найденная причина — блокировка по IP части серверов игры (см. закрепление серверов игр выше).
- **Меню падало, если служба обхода завершилась с кодом WFP** (0x8032000A, «object is referenced by other objects»). Теперь меню объясняет: Windows держит фильтры прошлого запуска; так бывает, если перезапускать обход при открытой игре с античитом. Закройте игру и запустите обход; не поможет — перезагрузите ПК.
- **Автоподбор предупреждает, прежде чем сменить основную стратегию, если включён Game Filter:** он проверяет сайты, а игру в матче не может.

## zapret 1.3

- **Telegram через сам zapret: встроенный мост.**
  - Обход Telegram не лечит: у нас режут адреса его дата-центров. Мост работает на вашем ПК: Telegram Desktop подключается к нему как к прокси, а мост гонит трафик через веб-версию Telegram, которую не режут. Ничего не скачивается: код моста (C#) лежит в сборке, Windows компилирует его сама.
  - Это перенос основной логики tg-ws-proxy от Flowseal (MIT). Свой пул готовых соединений: провайдер отбрасывает часть новых подключений к Telegram, а из пула Telegram получает уже открытое.
  - Проверено вживую: дата-центры DC2 и DC4 (там аккаунты почти всех из России) и их медиа отвечают через мост за 0,05–0,3 с, 24 запроса из 24. DC1, DC3 и DC5 (США и Азия) провайдер режет полностью, через мост они идут только там, где их не режут.
  - При первом запуске обхода (пункт 1) сборка предлагает мост сама, позже - Инструменты → 8. Мост работает с входа в Windows, без окна и без прав администратора; если его закрыть или он упадёт, Windows запустит его снова.
  - tg-ws-proxy, который ставила 1.2, мост заменяет: тот закрывается и убирается из автозапуска, а его ключ мост берёт себе - перенастраивать Telegram не нужно.
  - В строке состояния меню видно, работает ли Telegram. Проверка обходов замечает, что Telegram ждёт выключенный мост, и включает его одной кнопкой.
- Уведомления (Настройки → 10) хранят своё состояние в настройках.

  - Шапка меню и проверка обходов это замечают. Проверка обходов перезапускает их одной кнопкой, без прав администратора.
- **Инструменты → 6: исключить игру из обхода** по последнему трекеру, если с обходом она работает хуже, чем без него.

- **Настройки → 9: обновление zapret из меню.** Архив релиза сверяется по SHA-256 с GitHub. Настройки, рейтинг и ваши списки остаются, при сбое прежние файлы возвращаются.
- **Настройки → 10: уведомления Windows.** Приходят, когда служба обхода упала, Steam или Discord остались без сети после прокси, вышла новая версия или отработала автонастройка.
- Автоподбор проверяет и Steam (магазин и API): стратегия, которая его ломает, получает вред.
- Проверки гоняются на GitHub при каждом коммите. Появился README на английском.
- **Инструменты → 8: Telegram через tg-ws-proxy от Flowseal.**
  - Ставится по кнопке со страницы релизов Flowseal и сверяется по SHA-256. Работает в портативном режиме внутри `runtime\tg-ws-proxy`.
  - Запускается без прав администратора, одной кнопкой подключает Telegram Desktop. Есть автозапуск и удаление.
- **Инструменты → 9: очистка кэша Discord**, как у Flowseal: помогает, когда Discord не запускается или висит на обновлении.
- **Проверка обходов: проверки из диагностики Flowseal.**
  - Служба Base Filtering Engine: если она не работает, проверка её включает.
  - Программы, которые конфликтуют с обходом: AdGuard, Killer, Intel Connectivity Network Service, Check Point, SmartByte.
  - Папка сборки в OneDrive.
  - О найденном пишет и шапка меню.
- **Меню быстрее.** Шапка выводится в 3 раза быстрее (0,04 с вместо 0,12), первый раз — 0,4 с вместо 0,6:
  - стратегии не перечитываются из 27 файлов, пока файлы не менялись;
  - прокси проверяется через netstat, а не через медленный Get-NetTCPConnection;
  - SHA-256 файлов zapret2 шапка пересчитывает, только если файлы изменились (перед запуском обхода сверка по-прежнему полная);
  - задача уведомлений, ускорители и конфликты запрашиваются реже. Проверка обходов всегда смотрит свежее состояние.
- **Защита от подмены надёжнее.** Для папки в «Загрузках» или на рабочем столе снимаются и явные права других учётных записей: раньше они могли остаться.
