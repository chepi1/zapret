# История версий

## zapret 1.4.1

- **Поправка к 1.4: статтеры в NBA 2K27 не исправлены.** Игра лагает и на той же конфигурации, что в 1.1, а два матча без лагов на ней были совпадением.
  - Главная зацепка: провайдер блокирует по IP часть серверов игры на Amazon. Обход такую блокировку не снимает, а через VPN она не мешает.
- **Круг автосмены сайтов снова собирает автоподбор (откат 1.4).** Стандартный круг пускал ALT11 и ALT12 с разрезкой seqovl, и сайты на Akamai (Bing, Adobe, Sony и др.) висели на установке TLS. На лаги NBA 2K27 круг не влиял. У игры круг остаётся стандартным.
- **Обход запускается быстрее.** Запуск засчитывается, когда winws2 проработал чуть больше секунды, а не через фиксированные 3 секунды. Остановка ждёт, пока процессы завершатся, а не полсекунды впустую.
- **Меню открывается быстрее.** Проверка новых версий на GitHub (раз в 3 дня) идёт в фоне. Раньше при медленном GitHub она держала меню до 20 секунд.
- **Трекер показывает каждый рывок игры** (пауза в исходящих пакетах матча от 250 мс). Для каждого он пишет, с какими серверами игра и EAC обменивались пакетами за 1,5 с до рывка и во время него, и ждали ли они ответа. В итоге видно, какие соединения чаще всего оказываются рядом с рывками.
- **Автоподбор предупреждает, прежде чем сменить основную стратегию, если включён Game Filter.** Он проверяет сайты, а игру в матче не может.
- **Исправлено: меню падало, если служба обхода завершилась с кодом WFP** (например, 0x8032000A: «object is referenced by other objects»). Для этой ошибки появилась подсказка. Windows держит фильтры прошлого запуска; так бывает, если перезапускать обход при открытой игре с античитом. Нужно закрыть игру и запустить обход, а если не поможет — перезагрузить ПК.

## zapret 1.4

- **Исправлено. Статтеры в NBA 2K27 после автоподбора: FPS падал до 4, игра подвисала посреди матча.**
  - Круги автосмены для игры и для сайтов собирал автоподбор. Но через профили сайтов (сети хостингов, CloudFront) ходит и игра, а игру в матче автоподбор не проверяет: серверы 2K и EAC открываются почти со всеми стратегиями.
  - В круги попадали стратегии из одних фейков или одной разрезки: ALT10, SIMPLE FAKE ALT2, GENERAL (та же, что по умолчанию у Flowseal). Когда серверы игры переходили на них, игра подвисала.
  - Теперь у сайтов и игр всегда стандартный круг, как до автоподбора: с ним матчи без статтеров. Круги YouTube и Discord по-прежнему собирает автоподбор.
- **Серверы Valve снова обрабатываются, как в 1.1.** В 1.2 я исключил их, когда разбирался с Дотой. Доту тогда на самом деле ломал Steam, запомнивший выключенный прокси, и теперь это замечает проверка обходов (пункт 5).
- **Трекер показывает паузы между пакетами матча** и различает, кто пропадает: пакеты в сети или сама игра.

## zapret 1.3

- **Telegram через сам zapret: встроенный мост.**
  - Обход Telegram не лечит: у нас режут адреса его дата-центров. Мост работает на вашем ПК: Telegram Desktop подключается к нему как к прокси, а мост гонит трафик через веб-версию Telegram, которую не режут. Ничего не скачивается: код моста (C#) лежит в сборке, Windows компилирует его сама.
  - Это перенос основной логики tg-ws-proxy от Flowseal (MIT). Свой пул готовых соединений: провайдер отбрасывает часть новых подключений к Telegram, а из пула Telegram получает уже открытое.
  - Проверено вживую: дата-центры DC2 и DC4 (там аккаунты почти всех из России) и их медиа отвечают через мост за 0,05–0,3 с, 24 запроса из 24. DC1, DC3 и DC5 (США и Азия) провайдер режет полностью, через мост они идут только там, где их не режут.
  - При первом запуске обхода (пункт 1) сборка предлагает мост сама, позже - Инструменты → 8. Мост работает с входа в Windows, без окна и без прав администратора; если его закрыть или он упадёт, Windows запустит его снова.
  - tg-ws-proxy, который ставила 1.2, мост заменяет: тот закрывается и убирается из автозапуска, а его ключ мост берёт себе - перенастраивать Telegram не нужно.
  - В строке состояния меню видно, работает ли Telegram. Проверка обходов замечает, что Telegram ждёт выключенный мост, и включает его одной кнопкой.
- Уведомления (Настройки → 10) хранят своё состояние в настройках.

## zapret 1.2

- **Исправлено. Dota 2 не пускала в матч, кнопка «Играть» не нажималась.**
  - Часть ретрансляторов Valve (Datapacket во Франкфурте, Вене и Лондоне) есть в списке сетей Flowseal, и с Game Filter обход слал на них фейки.
  - Серверы Valve (Steam, Dota 2, CS2) теперь исключены во всех профилях, как серверы 2K.
  - Список `lists\ipset-valve.txt`: сети Valve и адреса ретрансляторов из официального конфига Steam. Обновляется вместе со списками (Настройки → 8 и автонастройка).
- Сканер и трекер помечают серверы Valve: обход их не трогает.
- **Steam и Discord, застрявшие на выключенном прокси.**
  - Они запоминают системный прокси при запуске. Если прокси выключили, они остаются без сети, хотя выглядят «в сети»: в Доте нет цен и не работает «Играть».
  - Шапка меню и проверка обходов это замечают. Проверка обходов перезапускает их одной кнопкой, без прав администратора.
- **Инструменты → 6: исключить игру из обхода** по последнему трекеру, если с обходом она работает хуже, чем без него.
- **Инструменты → 7: правила «напрямую» для Happ и других прокси.** Steam, Discord и игры идут мимо прокси. Файл кладётся на рабочий стол, домены копируются в буфер обмена.
- **Настройки → 9: обновление zapret из меню.** Архив релиза сверяется по SHA-256 с GitHub. Настройки, рейтинг и ваши списки остаются, при сбое прежние файлы возвращаются.
- **Настройки → 10: уведомления Windows.** Приходят, когда служба обхода упала, Steam или Discord остались без сети после прокси, вышла новая версия или отработала автонастройка.
- Автоподбор проверяет и Steam (магазин и API): стратегия, которая его ломает, получает вред.
- Проверки гоняются на GitHub при каждом коммите. Появился README на английском.
- **Инструменты → 8: Telegram через tg-ws-proxy от Flowseal.**
  - Ставится по кнопке со страницы релизов Flowseal и сверяется по SHA-256. Работает в портативном режиме внутри `runtime\tg-ws-proxy`.
  - Запускается без прав администратора, одной кнопкой подключает Telegram Desktop. Есть автозапуск и удаление.
- **Инструменты → 9: очистка кэша Discord**, как у Flowseal: помогает, когда Discord не запускается или висит на обновлении.
- **Проверка обходов: проверки из диагностики Flowseal.**
  - Служба Base Filtering Engine: если она не работает, проверка её включает.
  - Программы, которые конфликтуют с обходом: AdGuard, Killer, Intel Connectivity Network Service, Check Point, SmartByte.
  - Папка сборки в OneDrive.
  - О найденном пишет и шапка меню.
- **Меню быстрее.** Шапка выводится в 3 раза быстрее (0,04 с вместо 0,12), первый раз — 0,4 с вместо 0,6:
  - стратегии не перечитываются из 27 файлов, пока файлы не менялись;
  - прокси проверяется через netstat, а не через медленный Get-NetTCPConnection;
  - SHA-256 файлов zapret2 шапка пересчитывает, только если файлы изменились (перед запуском обхода сверка по-прежнему полная);
  - задача уведомлений, ускорители и конфликты запрашиваются реже. Проверка обходов всегда смотрит свежее состояние.
- **Защита от подмены надёжнее.** Для папки в «Загрузках» или на рабочем столе снимаются и явные права других учётных записей: раньше они могли остаться.

## zapret 1.0 — первый публичный выпуск

- **Сборка переименована: NBA2K27-zapret2 → zapret.**
  - Меню запускается файлом `zapret.bat`, архив — `zapret-v1.0.zip`.
  - Служба автозапуска теперь `zapret2-bypass` («zapret - обход DPI»), задача — `zapret autotune`. Просто `zapret` нельзя: так называется служба Flowseal.
  - Служба и задача прежней версии при первом запуске меню переносятся под новые имена сами, блок в hosts с прежними метками тоже узнаётся.
- **Проверка обходов одним пунктом (4)** вместо трёх прежних (C, I, H).
  - Проверяет подключение, VPN, прокси, игровые ускорители, другой обход, IPv6, hosts Flowseal и автосписок.
  - В конце — список исправлений: номера через пробел или «всё».
- **Меню проще и только с цифрами.**
  - Главный экран: одна строка состояния (работает ли обход, стратегия, автозапуск) и 6 пунктов: запуск, остановка, автоподбор, проверка обходов, настройки, инструменты.
  - В «Настройках» (5) у каждой настройки видно текущее значение. «Инструменты» (6): трекер, сканер, проверка провайдера, отчёт, диагностика.
  - На каждом экране свои номера по порядку, 0 — назад. Буквы прежних версий (T, S, U, A, C, P, R, D) работают с любого экрана.
  - Меню нарисовано табличкой в двойной рамке, все строки одной ширины.
  - Круги автосмены показаны на экране выбора стратегии (Настройки → 1).
  - `PROVERKA.bat` убран: проверка провайдера — в меню, Инструменты → 3.
  - Список стратегий умещается по одной строке на стратегию.
  - Строки о прокси и VPN убраны из шапки: они видны в проверке обходов и в автоподборе.
- **Автоподбор понятнее.**
  - Во время теста у каждой стратегии свой заголовок `[ 3/28] ALT12 мягкая` и строка результата под ним — видно, что проверяется сейчас и сколько осталось.
  - В итоге первым идёт балл, по которому выбирается лучшая (балл = пробито − вред), и место стратегии.
  - Если больше всех пробила другая стратегия, итог объясняет, почему она не лучшая: какие обычные сайты она ломает.
- **Исправлено. Telegram переставал подключаться после ExitLag или VPN.**
  - Пока трафик шёл через них, соединения рвались, и в автосписок попадали адреса серверов Telegram. Обход ломал на них запасной канал Telegram.
  - IP-адресам в автосписке не место: теперь они убираются перед каждым запуском.
- **Исправлено. Диагностика (Инструменты → 5) не запускалась:** командная строка winws2 (~13 тыс. символов) не помещалась в предел cmd.exe (8191).
- **Безопасность:**
  - перед каждым запуском файлы zapret2 сверяются с SHA-256 официального релиза;
  - папки с кодом закрываются на запись для всех, кроме администраторов и SYSTEM, чтобы программа без прав администратора не могла подменить скрипт, который потом выполнит служба;
  - диагностика больше не запускает команду из файла в `runtime\`.
- **Приватность:**
  - провайдер и страна определяются только по HTTPS (ipwho.is, ipinfo.io), запросов по HTTP больше нет;
  - в отчётах скрыто имя пользователя Windows;
  - список сайтов из автосписка попадает в отчёт только с согласия.
- **Пункт 2** перед удалением предлагает вернуть записи hosts и «предпочитать IPv4» и возвращает обычные права папке.
- **Исправлено. Автоподбор при ошибке или Ctrl+C:**
  - обход больше не остаётся выключенным;
  - тестовый winws2 (IPSet any, без автосмены) не остаётся работать в фоне.
- **Исправлено. Медленный запуск меню:** если GitHub не отвечает, меню больше не ждёт его при каждом открытии.
- **Исправлено. Сканер:**
  - по Ctrl+C останавливает запись журнала сети (раньше она шла до перезагрузки);
  - не падает на нераспознанном порте и при отсутствии `ipset-user.txt`.
- **Отчёт R:**
  - в него попадает последний лог трекера;
  - подробности автоподбора по каждому адресу остаются в `test-last.txt`, поэтому отчёт стал в 4 раза меньше.
- **Пункт 4:** стратегию можно выбрать и по имени (`EXP`, `ALT`, `SIMPLE FAKE ALT`).
- **Быстрее:**
  - шапка меню перерисовывается быстрее (запрос к планировщику заданий кэшируется);
  - запрос в автоподборе ждёт не 6, а 5 секунд: полный автоподбор короче примерно на минуту.
- **Для GitHub:**
  - README.md, лицензии сторонних компонентов;
  - `dev\` с конвертером стратегий Flowseal, проверками и сборкой архива.
